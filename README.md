
# TapFollow - Instagram Growth Request Website

A responsive website built using HTML, CSS and JavaScript.

## Features

- Instagram-inspired UI
- Responsive design
- Username submission
- Follower amount selection
- Google Sheets integration
- Automatic data storage
- Netlify hosting support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets
- Netlify

## Data Storage

Submitted usernames and requested amounts
are stored in Google Sheets.

## Deployment

Hosted using Netlify.
